DRWXRWXRWX

secound RWX this is for group R -> read , W -> write , X -> Execute isse pata chalta hai groupe ke pass kiten permission hai

third RWX this is for other R -> read , W -> write , X -> Execute isse pata chalta hai other ke pass
 kiten permission hai
